# 金融平台项目结构与测试指南（修复版）

## 1. 项目概述

"量融"金融平台是一个基于Spring Boot 3.5.6 + Vue.js 3的全栈Web应用，提供股票信息展示、用户管理和数据分析功能。项目采用前后端分离架构，后端使用Spring Boot框架，前端使用Vue.js框架。

### 1.1 技术栈
- **后端**: Spring Boot 3.5.6 + MyBatis + MySQL + Spring Security + JWT
- **前端**: Vue.js 3.2.13 + Element Plus + Vue Router + Vuex + Axios
- **数据库**: MySQL 8.0
- **构建工具**: Maven (后端) + npm (前端)
- **Java版本**: 17

## 3. 后端结构详解

### 3.1 主应用类
- **FinanceDashboardApplication.java**: Spring Boot应用启动类，使用`@SpringBootApplication`注解标记，包含main方法。

### 3.2 配置类 (config/)
- **SecurityConfig.java**: Spring Security安全配置，定义认证和授权规则，配置密码编码器。
- **WebConfig.java**: Web配置，实现`WebMvcConfigurer`接口，注册JWT拦截器。

### 3.3 控制器层 (controller/)
- **StockController.java**: 股票信息控制器，处理股票相关的HTTP请求。
  - `GET /api/stocks`: 获取所有股票信息
  - `GET /api/stocks/{stockCode}`: 根据股票代码获取股票信息
  - `POST /api/stocks`: 添加新股票
  - `POST /api/stocks/batch`: 批量添加股票
  - `PUT /api/stocks`: 更新股票信息
  - `DELETE /api/stocks/{stockCode}`: 删除股票
  - `POST /api/stocks/query`: 查询股票

- **UserController.java**: 用户控制器，处理用户相关的HTTP请求。
  - `POST /api/users/register`: 用户注册
  - `POST /api/users/login`: 用户登录
  - `GET /api/users/info`: 获取用户信息
  - `POST /api/users/logout`: 用户登出

### 3.4 数据传输对象 (dto/)
- **StockQueryDTO.java**: 股票查询数据传输对象，封装查询条件（关键词、行业）。
- **UserRegisterDTO.java**: 用户注册数据传输对象，封装用户注册信息。
- **UserLoginDTO.java**: 用户登录数据传输对象，封装用户登录信息。

### 3.5 实体类 (entity/)
- **StockInfo.java**: 股票信息实体类，映射数据库表结构，包含股票代码、名称、价格等信息。
- **User.java**: 用户实体类，映射数据库表结构，包含用户名、密码、邮箱等信息。
- **Role.java**: 角色实体类，映射数据库表结构，包含角色信息。

### 3.6 异常处理 (exception/)
- **GlobalExceptionHandler.java**: 全局异常处理器，使用`@RestControllerAdvice`注解，统一处理Controller层抛出的异常。

### 3.7 拦截器 (interceptor/)
- **JwtInterceptor.java**: JWT拦截器，实现`HandlerInterceptor`接口，验证请求中的JWT令牌。

### 3.8 数据访问层 (mapper/)
- **StockInfoMapper.java**: 股票信息Mapper接口，定义数据库操作方法。
- **UserMapper.java**: 用户Mapper接口，定义数据库操作方法。

### 3.9 服务层 (service/)
- **StockService.java**: 股票信息服务接口，定义股票相关的业务方法。
- **UserService.java**: 用户服务接口，定义用户相关的业务方法。
- **impl/**: 服务实现类
  - **StockServiceImpl.java**: 股票信息服务实现，实现股票相关的业务逻辑。
  - **UserServiceImpl.java**: 用户服务实现，实现用户相关的业务逻辑。

### 3.10 工具类 (utils/)
- **JwtUtil.java**: JWT工具类，用于生成和验证JWT令牌。
- **Result.java**: 统一返回结果类，封装API接口的返回结果，使用泛型支持不同类型的数据。

### 3.11 视图对象 (vo/)
- **UserVO.java**: 用户信息视图对象，用于封装展示层需要的数据，不包含敏感信息如密码。

### 3.12 资源文件 (resources/)
- **application.yml**: 应用配置文件，包含服务器端口、数据库连接、MyBatis配置、JWT配置等。
- **mapper/**: MyBatis映射文件
  - **StockInfoMapper.xml**: 股票信息SQL映射。
  - **UserMapper.xml**: 用户SQL映射。

## 4. 前端结构详解

### 4.1 配置文件
- **package.json**: 前端项目依赖配置，定义项目依赖和脚本，包含Vue.js、Element Plus、Axios等。
- **vue.config.js**: Vue项目配置，包含开发服务器配置、代理设置等。

- **index.js**: 路由配置文件，定义页面路由和路由守卫，包含登录验证逻辑。

## 5. 数据流转与交互

### 5.1 用户认证流程
1. 用户在前端输入用户名和密码，点击登录
2. 前端调用`/api/users/login`接口，发送用户信息
3. 后端UserController接收请求，调用UserService验证用户
4. UserService验证成功后，调用JwtUtil生成JWT令牌
5. 后端返回JWT令牌给前端
6. 前端将令牌存储在localStorage中
7. 后续请求中，前端通过请求拦截器将令牌添加到请求头
8. 后端JwtInterceptor拦截请求，验证令牌有效性

### 5.2 股票信息查询流程
1. 用户在前端访问股票列表页面
2. 前端调用`/api/stocks`接口获取股票列表
3. 后端StockController接收请求，调用StockService
4. StockService调用StockInfoMapper查询数据库
5. 数据库返回股票信息，通过Mapper映射为Java对象
6. StockService将股票信息返回给Controller
7. Controller将结果封装为统一返回格式
8. 前端接收数据并渲染到页面

### 5.3 股票信息添加流程
1. 用户在前端填写股票信息，点击提交
2. 前端调用`/api/stocks`接口，发送股票信息
3. 后端StockController接收请求，调用StockService
4. StockService调用StockInfoMapper插入数据库
5. 数据库插入成功后返回结果
6. 前端接收成功响应，更新页面显示

### 6.7 常见问题及解决方案

#### 6.7.1 后端问题
1. **数据库连接失败**
   - 检查MySQL服务是否启动
   - 检查application.yml中的数据库连接配置是否正确
   - 检查数据库用户名和密码是否正确

2. **JWT验证失败**
   - 检查JWT配置是否正确
   - 检查请求头中是否正确添加了Authorization字段
   - 检查JWT令牌是否过期

3. **跨域问题**
   - 在后端添加跨域配置
