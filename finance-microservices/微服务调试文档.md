# 量融金融平台微服务调试文档

## 1. 文档概述

本文档提供了量融金融平台微服务架构的详细调试指南，包括环境准备、服务启动、问题排查、性能调优等方面的内容。

## 2. 环境准备

### 2.1 基础环境要求

#### 软件环境
- **Java**: JDK 17或更高版本
- **Maven**: 3.6.0或更高版本
- **Redis**: 6.0或更高版本
- **Git**: 用于配置中心代码管理

#### 硬件要求
- **内存**: 最少8GB，推荐16GB
- **存储**: 最少20GB可用空间
- **网络**: 稳定的网络连接

### 2.2 开发工具推荐

#### IDE
- **IntelliJ IDEA**: 2023.1或更高版本
- **VS Code**: 配置Java扩展包

#### 辅助工具
- **Postman**: API接口测试
- **Redis Desktop Manager**: Redis可视化管理
- **Git客户端**: SourceTree或GitKraken

### 2.3 环境验证

#### Java环境验证
```bash
java -version
mvn -version
```

#### Redis环境验证
```bash
redis-cli ping
# 应该返回 PONG
```

#### 网络连通性验证
```bash
# 检查端口是否可用
netstat -an | grep 8761  # 注册中心端口
netstat -an | grep 8888  # 配置中心端口
netstat -an | grep 8080  # 网关端口
```

## 3. 服务启动调试

### 3.1 启动顺序与服务依赖

```
启动顺序：
1. finance-registry (注册中心) - 端口8761
2. finance-config (配置中心) - 端口8888
3. finance-gateway (API网关) - 端口8080
4. 其他业务服务 (按需启动)
```

### 3.2 注册中心调试

#### 启动命令
```bash
cd finance-registry
mvn spring-boot:run
```

#### 验证启动成功
1. **控制台输出检查**:
   ```
   金融平台注册中心启动成功！
   Started FinanceRegistryApplication in X.XXX seconds
   ```

2. **访问管理界面**:
   ```
   URL: http://localhost:8761
   用户名: admin
   密码: admin123
   ```

3. **健康检查端点**:
   ```bash
   curl http://localhost:8761/actuator/health
   ```

#### 常见问题排查

**问题1: 端口被占用**
```bash
# 查找占用端口的进程
netstat -tulpn | grep 8761
# 杀死进程
kill -9 <PID>
```

**问题2: 无法访问管理界面**
- 检查防火墙设置
- 确认安全配置是否正确
- 查看应用日志中的错误信息

**问题3: 服务注册失败**
- 检查网络连接
- 确认Eureka Server地址配置正确
- 查看客户端服务日志

### 3.3 配置中心调试

#### 启动命令
```bash
cd finance-config
mvn spring-boot:run
```

#### 验证启动成功
1. **控制台输出检查**:
   ```
   金融平台配置中心启动成功！
   Started FinanceConfigApplication in X.XXX seconds
   ```

2. **访问配置接口**:
   ```bash
   # 获取默认配置
   curl http://localhost:8888/finance-gateway/default
   
   # 获取特定环境配置
   curl http://localhost:8888/finance-gateway/dev
   ```

3. **健康检查端点**:
   ```bash
   curl http://localhost:8888/actuator/health
   ```

#### 常见问题排查

**问题1: Git仓库连接失败**
- 检查Git仓库地址是否正确
- 确认网络连接和权限
- 验证用户名和密码配置

**问题2: 配置文件读取失败**
- 检查Git仓库中的文件结构
- 确认文件命名规范
- 查看配置中心日志

**问题3: 配置刷新失败**
- 检查/actuator/refresh端点是否可用
- 确认客户端配置正确
- 查看网络连接状态

**问题1: 路由不生效**

- 查看网关日志中的路由信息

**问题2: 认证过滤器异常**
- 检查JWT配置
- 确认JWT工具类是否正确加载
- 查看过滤器日志

**问题3: 限流功能异常**
- 检查Redis连接状态
- 确认限流配置参数
- 查看Redis中的限流数据

## 6. 性能调试

### 6.1 响应时间监控

#### 接口响应时间测试
```bash
# 使用time命令测量响应时间
time curl http://localhost:8080/api/users/info

# 使用curl的-w参数获取详细时间信息
curl -w "@curl-format.txt" -o /dev/null -s http://localhost:8080/api/users/info
```

#### curl-format.txt内容
```
     time_namelookup:  %{time_namelookup}\n
        time_connect:  %{time_connect}\n
     time_appconnect:  %{time_appconnect}\n
    time_pretransfer:  %{time_pretransfer}\n
       time_redirect:  %{time_redirect}\n
  time_starttransfer:  %{time_starttransfer}\n
                     ----------\n
          time_total:  %{time_total}\n
```

## 11. 常见问题解决方案

### 11.1 启动问题

#### 问题: 服务启动失败
**症状**: 服务启动时抛出异常，无法正常启动
**解决方案**:
1. 检查端口是否被占用
2. 检查依赖服务是否已启动
3. 查看启动日志中的错误信息
4. 检查配置文件格式是否正确

#### 问题: 服务注册失败
**症状**: 服务无法注册到Eureka
**解决方案**:
1. 检查Eureka服务是否正常运行
2. 确认Eureka客户端配置正确
3. 检查网络连接
4. 查看服务日志中的注册信息

### 11.2 运行时问题

#### 问题: 请求超时
**症状**: API请求响应超时
**解决方案**:
1. 检查目标服务是否正常运行
2. 调整超时配置
3. 检查网络连接
4. 查看服务性能指标

#### 问题: 认证失败
**症状**: JWT令牌验证失败
**解决方案**:
1. 检查JWT配置是否正确
2. 确认令牌格式正确
3. 检查令牌是否过期
4. 验证密钥配置

### 11.3 性能问题

#### 问题: 响应缓慢
**症状**: API响应时间过长
**解决方案**:
1. 检查数据库查询性能
2. 优化代码逻辑
3. 增加缓存使用
4. 调整JVM参数

#### 问题: 内存泄漏
**症状**: 内存使用持续增长
**解决方案**:
1. 生成内存堆转储文件
2. 使用内存分析工具分析
3. 检查代码中的资源释放
4. 调整JVM内存配置

## 13. 调试最佳实践

### 13.1 日志记录最佳实践

1. **合理使用日志级别**: DEBUG、INFO、WARN、ERROR
2. **结构化日志**: 使用JSON格式便于分析
3. **上下文信息**: 记录请求ID、用户ID等关键信息
4. **避免敏感信息**: 不要在日志中记录密码等敏感数据

### 13.2 错误处理最佳实践

1. **统一异常处理**: 使用全局异常处理器
2. **错误码规范**: 定义清晰的错误码体系
3. **错误信息**: 提供有用的错误信息
4. **错误监控**: 建立错误告警机制

### 13.3 性能优化最佳实践

1. **监控指标**: 建立完善的性能监控体系
2. **基准测试**: 定期进行性能基准测试
3. **容量规划**: 根据业务增长进行容量规划
4. **性能调优**: 持续进行性能优化
